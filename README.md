💛 MenteConecta

Bem-vindo(a) ao repositório do MenteConecta! Nosso objetivo é criar uma plataforma online para ajudar jovens adultos com ansiedade, conectando-os a profissionais especializados no município de Santo André.

✨ Sobre o Projeto

O MenteConecta é uma iniciativa voltada à saúde mental, oferecendo recursos como:

📚 Documentações e materiais psicológicos

💌 Mensagens motivacionais diárias

🌬️ Tutoriais de técnicas de respiração

🤝 Contatos de ONGs e grupos de apoio

💬 Chat particular para conexão com psicólogos voluntários

🚀 Tecnologias Utilizadas

O projeto está sendo desenvolvido com as seguintes tecnologias:

Front-end: HTML, CSS, JavaScript

Back-end: Node.js

Banco de Dados: MongoDB

Outras ferramentas: Figma (para prototipagem), Firebase (para autenticação)

💖 Contribuindo

Quer contribuir com o projeto? Fique à vontade! Qualquer ajuda é bem-vinda. Para isso:

Faça um fork deste repositório

Crie uma branch com sua feature:

git checkout -b minha-feature

Faça o commit das suas alterações:

git commit -m 'Adicionando nova feature'

Faça um push para a sua branch:

git push origin minha-feature

Abra um Pull Request
